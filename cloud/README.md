# 클라우드 이관 상태

현재 단계는 GitHub Actions의 새 비로그인 브라우저에서 ChatGPT와 Gemini의 접근 상태를 확인하는 시험입니다. 질문 전송, 운영 저장, 매일 예약은 아직 켜지지 않았습니다.

1. `Radar cloud access probe` 실행 결과와 화면 증거를 확인합니다.
2. 입력창과 비로그인 근거가 확인된 서비스에서 현재 조사 질문을 새 대화에 한 번 보내 실제 응답까지 검증합니다. 접근 제한·로그인 요구·CAPTCHA가 있으면 중단합니다. 사용자 PC, IP 교체 또는 우회 도구로 클라우드 결과를 대신하지 않습니다.
3. Supabase에 기존 본인 계정 기록만 저장하는 서버 전용 인증 경로를 구성합니다. 키·로그인 정보는 GitHub Secrets에 두고 공개 저장소나 페이지에 넣지 않습니다. 기존의 `user_id,date,ai,question` 중복 방지와 실패 응답 제외 규칙을 유지합니다.
4. 답변 원문과 검토한 추천 치과 목록이 일치하는지 확인한 후 운영 데이터 저장을 시험합니다. API 응답을 웹 응답으로 저장하지 않습니다.
5. 한국시간 오전 9:30 예약과 실패 알림을 연결합니다. GitHub 예약은 실행이 지연될 수 있으므로 정각 보장이 필요한 경우 별도 예약 서비스를 사용합니다.
6. PC를 끈 상태의 실제 예약 실행과 페이지 반영을 검증한 뒤 기존 Codex PC 예약을 중지합니다.

접근 시험이 막히면 자동 수집이 된 것으로 표시하지 않습니다. API 조사로 기준을 변경하려면 웹 조사와의 차이를 설명하고 별도 결정합니다.

Actions의 `summary.json`은 접근 가능성만 나타냅니다. `candidate_for_question_test`는 수집 성공이 아닙니다. 증거 파일은 비로그인 공개 화면만 포함하며 3일 후 삭제됩니다.
